# Security

Found a security problem in Trivvoly? Please report it privately: on GitHub, open the
**Security** tab of this repository and choose **Report a vulnerability**. Please don't open a
public issue for it.

You'll get a reply within a few days. Once it's fixed, you're welcome to be credited.

How Trivvoly protects players and quizmasters is described in [README.md](README.md#safety)
and [docs/HOSTING.md](docs/HOSTING.md).
